# research/personaplex_train: LoRA fine-tuning of PersonaPlex (V1, V3, V4)

This folder holds the training scripts of record for the PersonaPlex 7B LoRA adapters. Training runs on the patched kyutai-labs moshi-finetune; `UPSTREAM.md` gives the repo, commit, patch and how to apply it. The code was copied from pod1 `/workspace/hinglish/{trainer,infer}`, the top-level `queue_*.sh` and `pick_best.py`, and `trainer/voice_codes/*.py`. Sources and md5s are in `PROVENANCE.tsv`. `trainer/RECON.md` is the original reconnaissance of PersonaPlex and moshi-finetune internals.

## Stages and scripts

| Stage | Script |

## Inputs and outputs

Training manifests are `$HINGLISH_ROOT/data/<V>/{train/train.jsonl,heldout/...}` (stereo wav plus alignment JSON) from the HF dataset `shivamgupta/hinglish-s2s-synthetic-calls`. Each run writes `$RUNS_ROOT/<run>/` containing `run.log`, `args.yaml`, `metrics.csv`, `eval_metrics.csv`, `loss.png` and `checkpoints/checkpoint_XXXXXX/consolidated/{lora.safetensors,config.json}`. The released V4 adapter is HF `shivamgupta/personaplex-hinglish-v4-lora`.

## Shared modules (from `packages/personaplex_lora`)

- `infer/driver_lora.py` imports `lora_merge` from `packages/personaplex_lora/infer` (env `PP_LORA_INFER_DIR`) and falls back to its own directory.
- `trainer/verify_sample.py` uses the same `lora_merge` and the voice codes in `packages/personaplex_lora/trainer/voice_codes` (env `PP_VOICE_CODES_DIR`).
- `trainer/merge_lora.py` (the eval-driver hook) is in `packages/personaplex_lora/trainer/`.
