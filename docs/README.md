# docs/

These are internal working documents, copied from the development folder. Paths in them such as `results/...`,
`ops/...` and `/root/...` refer to that folder and the dev boxes. Not every one exists in this repo; for example,
`results/` (raw test outputs) is not committed.

| file | what |
|---|---|
| `GO_LIVE.md` | go-live runbook for RunPod Serverless + the Hugging Face Space, plus what is live now |
| `DECISIONS.md` | append-only decision log (D-BAKE, D-GOLIVE, D-ROUTER-V2, D-LOCAL, D-SCRIPT-PANEL, D-MONOREPO, ...) |
| `DESIGN.md` | the frozen serverless design (2026-10-04) and its amendments |
| `SERVERLESS_NOTES.md` | the older "start here" (2026-10-05): architecture, security model, risks, test plan. Where it disagrees with `GO_LIVE.md` or `DECISIONS.md`, those win |
